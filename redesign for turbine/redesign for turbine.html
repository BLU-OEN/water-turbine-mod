Install & understand the preview

Download the ZIP, place it in your instance’s resourcepacks folder, then enable it above the mod’s resources in Minecraft’s Resource Packs menu. Keep the original mod installed. This is a client resource pack; no server installation is required.

The viewer uses the exported cuboids, UV coordinates and pixel textures. Its studio lighting and exploded view are presentation aids. Confirm appearance in Minecraft before treating these assets as release tested. Source geometry can be imported into Blockbench as a Java Block/Item model.
