# Monochrome turbine

The approved beveled white body with flat panels and a square cable mounting foot, black trim and swept rotor are included in Water Turbine **1.1.1**. No resource pack is required. The optional pack here mirrors the built-in models and requires 1.1.1 for the animated rotor.

The existing intake/outlet bubble cones remain built into the block unchanged. Waterlogging drives both the rotor and bubbles; generation and energy output are unchanged.

Canonical asset source: `../tools/generate_turbine_assets.py`. Run it with Python 3 to regenerate the models and textures in `src/main/resources`, synchronize this pack, and rebuild its ZIP. The older `build.mjs`, JSON and HTML in this folder are historical design experiments, not the 1.1.1 asset generator.
